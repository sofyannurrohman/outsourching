# Job Portal & Outsourcing Platform Skill

This skill defines the technical standards, architectural patterns, and design principles for the Job Portal & Outsourcing Platform. It is designed for a premium SaaS experience, focusing on high performance, clean code, and a luxury "Black, White, and Gold" aesthetic.

## 1. Technical Stack

| Layer | Technology | Purpose |
| :--- | :--- | :--- |
| **Backend** | Golang 1.22+ (Gin Gonic) | High-performance REST API, Business Logic |
| **Frontend** | Next.js 14 (App Router) | Premium SSR/SSG UI, SEO-friendly pages |
| **Auth** | JWT + bcrypt | Stateless authentication, Secure password hashing |
| **Database** | PostgreSQL 16 | Primary relational data store |
| **Cache** | Redis 7 | Session management, Rate limiting, Notification queue |
| **Storage** | VPS storage | CVs, Company Logos, Avatars |
| **Styling** | Tailwind CSS 3.x and ShadCN UI | Premium UI with "Dark Blue, White, Gold" palette |
| **State** | Zustand | Lightweight client-side state management |

## 2. Architecture & Design

### Backend (Golang Gin - Clean Architecture)
Follow a strict separation of concerns:
- **`cmd/`**: Entry point (`main.go`).
- **`internal/handler/`**: HTTP request/response handling. No business logic.
- **`internal/service/`**: Core business logic. Communicates with `repo`.
- **`internal/repo/`**: Database interactions using **GORM**.
- **`internal/model/`**: GORM database entities.
- **`internal/dto/`**: Data Transfer Objects for requests and responses.
- **`internal/middleware/`**: Auth, Logging, Rate Limiting, CORS.
- **`internal/config/`**: Environment variable management.

### Frontend (Next.js 14 - Premium SaaS UI)
- **Palette**: Black (#000000), White (#FFFFFF), and Gold (#D4AF37 / #C5A028).
- **Typography**: Modern, sans-serif (e.g., *Inter*, *Outfit*, or *Montserrat*).
- **UI Components**: Use **shadcn-ui** components styled with the gold/black theme.
- **UX**: Smooth transitions, micro-animations (Framer Motion), and responsive layouts.

## 3. Database Schema (GORM Models)
All tables use **UUID** primary keys and **Soft Deletes**.

- **`users`**: Auth credentials and roles (`talent`, `company`, `admin`).
- **`talents`**: Profile details, skills, CV URL, `pool_status` (pending, active).
- **`companies`**: Profile, industry, subscription details, verification status.
- **`jobs`**: Job postings linked to companies, status (draft, open, closed).
- **`applications`**: Talent applications to jobs, status (shortlisted, hired, etc.).
- **`contracts`**: Outsourcing contracts between talent and client, generated by admin.
- **`talent_pool_requests`**: On-demand outsourcing requests from companies.

## 4. Workflows & Rules

### API Response Standard
Always use a uniform response structure:
```json
{
  "success": true,
  "data": { ... },
  "meta": { "total": 100, "page": 1 }, // For lists
  "error": null
}
```

### Authentication & Authorization
1. **JWT**: Use Bearer tokens with `sub`, `role`, and `email` claims.
2. **Middleware**:
   - `Auth()`: Validates the token.
   - `RoleGuard(roles ...string)`: Restricts access to specific roles.

### File Uploads
- CVs (PDF) and Images (JPG/PNG).
- Max 5MB.
- Use pre-signed URLs for private CV access.

### Design Principles (Black & Gold)
- **Backgrounds**: Deep black or off-white.
- **Accents**: Gold gradients for primary buttons, borders, and hover states.
- **Text**: High contrast white on black, or dark grey on white.
- **Cards**: Subtle gold borders (1px) for a luxury feel.

## 5. Development Steps

1. **Backend Bootstrap**: Initialize Go modules, setup Gin, GORM, and Config loader.
2. **DB Migration**: Create models and perform `AutoMigrate`.
3. **Core Logic**: Implement Auth, Talent Profile, and Job Management.
4. **Frontend Scaffold**: Next.js App Router, Tailwind, and shadcn-ui setup.
5. **UI Implementation**: Auth pages -> Public Job Board -> Role-based Dashboards.
6. **Integration**: Connect frontend to backend API, handle state with Zustand.
7. **Infrastructure**: Dockerize services and setup Nginx reverse proxy.
